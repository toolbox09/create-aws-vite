# AI 사업성 분석 기획 명세서

## 1. 기능 개요

토지(필지)를 입력하면 AI가 건축용도별 복수 설계안을 자동 생성하고, 각 설계안에 대해 **분양 수익**과 **임대 수익**을 산출하는 사업성 분석 시스템.

### 핵심 구조

```
프로젝트 (1개 토지)
├── 서브프로젝트 A (건축용도: 상가주택)
│   ├── 설계안 1 (Report)
│   ├── 설계안 2
│   └── 설계안 3
├── 서브프로젝트 B (건축용도: 업무시설)
│   ├── 설계안 1
│   └── 설계안 2
└── ...
```

- 프로젝트 1개 = 필지 1개 이상
- 서브프로젝트 = 건축용도별 그룹
- 설계안(Report) = AI가 생성한 개별 건축 설계 + 수익성 데이터

### 분석 모드

| 모드 | 목적 | 핵심 지표 |
|------|------|----------|
| **분양** | 건물을 지어 팔 때의 수익 | 총 분양가, 분양수익, 분양수익률 |
| **임대** | 건물을 지어 임대할 때의 수익 | 연 임대료, 임대수익, 임대수익률 |

## 3. API 명세

### 3.1 프로젝트 생성

```
POST /api/ai-feasibility/projects
```

**Request Body:**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| pnu | string[] | Y | 필지 번호 배열 |
| email | string | Y | 결과 알림 이메일 |
| options.projectUseArea | string | Y | 용도지역 |
| options.buildingType | string | N | 건축용도 (미지정 시 전체) |
| options.buildingCoverageRatio | number | N | 건폐율 |
| options.floorAreaRatio | number | N | 용적률 |
| options.buildingStoriesMax | number | N | 최고층수 |
| options.buildingStoriesMin | number | N | 최저층수 |
| options.floorHeight | number | N | 층고 |

**Response:** `{ pid: number }`

### 3.2 프로젝트 목록 조회

```
GET /api/ai-feasibility/projects?page={page}&size={size}
```

**Response:** 페이징 처리된 프로젝트 기본 정보 목록

### 3.3 프로젝트 상태 조회 (폴링용)

```
GET /api/ai-feasibility/projects/{pid}/status
```

**Response:** `{ status: "WAITING" | "RUNNING" | "FINISHED" | "FAILED" }`

- 클라이언트에서 10초 간격 폴링
- FINISHED 또는 FAILED 시 폴링 중단

### 3.4 프로젝트 개요 조회

```
GET /api/ai-feasibility/projects/{pid}/overview
```

**Response:** ProjectOverview (2.2절 참조)

### 3.5 프로젝트 결과 조회 (전체 데이터)

```
GET /api/ai-feasibility/projects/{pid}/results
```

**Response:** 서브프로젝트 + 설계안 + 건축개요 + 층별정보 + 비용 전체 데이터

### 3.6 3D 뷰어 URL 조회

```
GET /api/ai-feasibility/projects/{pid}/reports/{rid}/viewer-url
```

**Response:** `{ url: string }`

### 3.7 첨부파일 URL 조회

```
GET /api/ai-feasibility/projects/{pid}/reports/{rid}/files
```

**Response:** FilePath (2.8절 참조, 각 필드는 presigned URL)

## 4. 계산 로직

### 4.1 비용 계산

```
총 건축비 = 공사비 + 설계비 + 감리비 + 철거비 + 기타부대비
총 사업비 = 토지매입비 + 총 건축비
```

### 4.2 분양 수익 계산

```
총 분양가 = Σ(층별 전용면적 × m²당 분양가)
분양수익 = 총 분양가 - 총 사업비
분양수익률(%) = (분양수익 / 총 사업비) × 100
```

### 4.3 금융비용 계산

```
토지 대출금 = 토지매입비 × 대출비율 / 100
토지 월이자 = round(토지 대출금 × 금리 / 12)
토지 연이자 = 토지 월이자 × 12

건축 대출금 = 총 건축비 × 대출비율 / 100
건축 월이자 = round(건축 대출금 × 금리 / 12)
건축 연이자 = 건축 월이자 × 12

총 연이자 = 토지 연이자 + 건축 연이자
```

### 4.4 임대 수익 계산

```
연 임대료 = Σ(층별 월임대료) × 12
임대수익 = 연 임대료 - 총 연이자
임대수익률(%) = (임대수익 / 총 연이자) × 100
```

### 4.5 단위 환산

```
1평 = 3.30579 m²
1m² ≈ 0.3025 평

면적 환산: areaToPy(m2) = m2 / 3.30579
단가 환산: priceToPy(원/m²) = 원/m² × 3.30579
```

### 4.6 설계안 정렬 기준 (추천순)

1. 용적률 내림차순
2. (동률 시) 분양수익 내림차순
3. (동률 시) 월임대료 내림차순

## 5. 화면 명세

### 5.1 프로젝트 개요 페이지

**경로:** `/ai/project?pid={pid}`

#### 헤더

- 프로젝트명 (title)
- 우측: 면적 단위 토글 (m² ↔ 평)

#### 설계 개요 섹션

2열 그리드로 프로젝트 기본 정보 표시:

| 항목 | 값 형식 |
|------|--------|
| 용도지역 | 텍스트 |
| 용도지구 | 텍스트 (없으면 "-") |
| 대지면적 | {값}{단위} |
| 지목 | 텍스트 |
| 법적 건폐율 | {값}% |
| 법적 용적률 | {값}% |

#### AI 사업성 분석 결과 섹션

**상태별 표시:**

| 상태 | 표시 내용 |
|------|---------|
| WAITING / RUNNING | 로딩 애니메이션 + "AI 사업성 분석이 시작되었습니다." |
| FINISHED | 서브프로젝트 목록 (아래 상세) |
| FAILED | 에러 아이콘 + 에러 메시지 + "AI사업성 분석 다시하기" / "이전으로" 버튼 |

#### 서브프로젝트 카드 (FINISHED 시)

각 건축용도별로 1개씩 카드 표시. 카드 내부:

```
┌─────────────────────────────────────────────────────┐
│ ① 상가주택                                          │
├──────────┬──────────────────────────────────────────┤
│          │  용적률        분양수익(률)    ┌────────┐ │
│  썸네일   │  199.5%       3억원 (7.1%)   │ 연면적  │ │
│  이미지   │              ─────────────   │ 1,248m² │ │
│ 240×224  │              월 임대수익(률)  │전용면적 │ │
│          │              92만원 (4.8%)   │ 890m²   │ │
│          │                              │(71.3%)  │ │
│          │                              │[상세보기]│ │
└──────────┴──────────────────────────────┴────────┘ │
```

- 용적률: 해당 용도의 최고 용적률 (파란색 강조)
- 분양수익(률): 억 단위 표시
- 월 임대수익(률): 자동 단위 (만/억)
- 연면적, 전용면적(률): m² 표시
- **"상세 보기"** 클릭 → 설계안 상세 페이지로 이동

### 5.2 건축용도별 보고서 목록 페이지

**경로:** `/ai/project/sub?pid={pid}&buildingType={code}`

#### 레이아웃

```
┌──────┬──────────────────────────────────────────┐
│ 건축  │  ← 전체 결과로                           │
│ 용도  │  AI 사업성 분석 결과                      │
│ 사이드 │                                          │
│ 탭    │  ┌─ 1순위 설계안 (메인 카드, 큰 사이즈) ─┐ │
│      │  │  썸네일 | 용적률 / 수익 / 면적 / 상세보기│ │
│ 상가주택│ └────────────────────────────────────────┘ │
│ 업무시설│                                          │
│ 다세대 │  ── 전체 순위 ──                          │
│ 단독  │  2순위 카드 | 3순위 카드 | 4순위 카드       │
│ 상업  │                                          │
└──────┴──────────────────────────────────────────┘
```

- 좌측 사이드: 건축용도 탭 (클릭 시 같은 페이지에서 buildingType 전환)
- "전체 결과로" 버튼: 프로젝트 개요 페이지로 복귀
- 1순위 메인 카드: 대형 카드 (5.1절의 서브프로젝트 카드와 동일 형태)
- 2순위 이하: 소형 카드 목록

#### 수익성 요약 배너 (FsResult)

분양/임대 모드에 따라 다른 수식 표시:

**분양 모드:**
```
총 분양가  -  지출비용  =  분양수익(률)
3,200만원     2,990만원    210만원(7.0%)
```

**임대 모드:**
```
연 임대료  -  금융비용  =  순 임대수익(률)
1,104만원    1,052만원     52만원(4.9%)
```

- 금액은 만원 단위로 표시
- 수익률은 소수점 1자리

#### 탭 2: 매출

층별 분양/임대 수익 테이블. **(사용자 편집 가능)**

**단위:** 천원

**컬럼 구성 (분양 모드):**

| 컬럼 | 정렬 | 편집 | 설명 |
|------|------|------|------|
| 구분 | 중앙 | X | 주용도 (근린생활시설, 주차장 등) |
| 층 | 중앙 | X | 층 번호 (지하: B1, B2) |
| 전용면적({단위}) | 우 | X | |
| 공용면적({단위}) | 우 | X | |
| 공급면적({단위}) | 우 | X | |
| 전용률(%) | 우 | X | |
| {단위}당 분양가 | 우 | **O** | 숫자 입력, 천단위 구분 |
| 분양가 | 우 | X | = 전용면적 × 단가 / 1000 |

**컬럼 구성 (임대 모드):**

| 컬럼 | 정렬 | 편집 | 설명 |
|------|------|------|------|
| 구분 | 중앙 | X | (동일) |
| 층 | 중앙 | X | (동일) |
| 전용면적({단위}) | 우 | X | (동일) |
| 공용면적({단위}) | 우 | X | (동일) |
| 공급면적({단위}) | 우 | X | (동일) |
| 전용률(%) | 우 | X | (동일) |
| 월임대료 | 우 | **O** | 숫자 입력, 천단위 구분 |
| 연임대료 | 우 | X | = 월임대료 × 12 / 1000 |

**행 정렬:** 층 번호 내림차순 (최상층 → 지하)

**하단 합계:**
- 분양 모드: "총 분양가" + 합산 금액
- 임대 모드: "총 임대료" + 합산 금액

**편집 동작:**
- {단위}당 분양가 변경 → 해당 층 분양가 재계산 → 총 분양가 재계산 → 수익성 요약 갱신
- 월임대료 변경 → 해당 층 연임대료 재계산 → 총 임대료 재계산 → 수익성 요약 갱신
- 면적 단위 전환 시 → 단가도 함께 환산 (m²당 ↔ 평당)

#### 탭 3: 사업비용

3개 섹션으로 구성. **(사용자 편집 가능)**

**단위:** 천원 (금융비 제외)

##### 섹션 A: 매입비용

3열 테이블:

| 대지면적 | {단위}당 가격 | 토지매입 |
|---------|-------------|---------|
| {값}{단위} (읽기전용) | {값} (읽기전용, 자동계산) | **{값} (편집 가능)** |

- 토지매입 변경 → {단위}당 가격 자동 재계산
- {단위}당 가격 = 토지매입비 / 대지면적

##### 섹션 B: 건축비용

좌측: 연면적 테이블

| 지상 | 지하 | 계 |
|------|------|-----|
| {값} | {값} | {값} |

우측: 건축비 단가/총액 테이블

| 단가 항목 (편집 가능) | 총액 (자동계산) |
|--------------------|---------------|
| {단위}당 공사비: **{값}** | 공사비: {값} |
| {단위}당 설계비: **{값}** | 설계비: {값} |
| {단위}당 감리비: **{값}** | 감리비: {값} |
| {단위}당 철거비: **{값}** | 철거비: {값} |
| 기타 부대비: {값} (읽기전용) | **건축비 총계: {값}** (강조) |

- 단가 변경 → 총액 = 연면적 × 단가 자동 재계산
- 면적 단위 전환 시 → 단가도 함께 환산

##### 섹션 C: 금융비용

2열 레이아웃: 좌측 "매입비", 우측 "건축사업비"

각 열의 구조 동일:

| 입력 항목 | 표시 항목 |
|----------|----------|
| 비율: **{값}%** (편집) | 총액: {값}원 (읽기전용) |
| 금리: **{값}%** (편집) | 이자(월): {값}원 (읽기전용, 강조) |
| 대출금: **{값}원** (편집) | 이자(연): {값}원 (읽기전용, 강조) |

**편집 연동:**
- 비율 변경 → 대출금 = 총액 × 비율 / 100 자동 계산
- 대출금 변경 → 비율 = 총액 / 대출금 × 100 자동 계산
- 금리 또는 대출금 변경 → 월이자 = round(대출금 × 금리 / 12), 연이자 = 월이자 × 12

## 6. 사용자 편집 가능 항목 요약

모든 편집은 클라이언트 사이드에서 실시간 재계산. 서버 저장 없음 (What-if 분석 용도).

| 위치 | 편집 항목 | 재계산 영향 |
|------|---------|-----------|
| 매출 탭 | m²당 분양가 (층별) | → 분양가 → 총 분양가 → 분양수익/수익률 |
| 매출 탭 | 월임대료 (층별) | → 연임대료 → 총 임대료 → 임대수익/수익률 |
| 사업비용 > 매입비용 | 토지매입비 | → 총 사업비 → 분양수익률, 금융비용 → 임대수익률 |
| 사업비용 > 건축비용 | 단가 (공사/설계/감리/철거) | → 각 총액 → 건축비 총계 → 총 사업비 → 수익률 |
| 사업비용 > 금융비용 | 대출 비율 | ↔ 대출금 연동 → 이자 재계산 → 임대수익률 |
| 사업비용 > 금융비용 | 대출금 | ↔ 비율 연동 → 이자 재계산 → 임대수익률 |
| 사업비용 > 금융비용 | 금리 | → 이자 재계산 → 임대수익률 |
| 헤더 | 면적 단위 (m²↔평) | → 모든 면적 표시 + 면적당 단가 환산 |
| 헤더 | 분석 모드 (분양↔임대) | → 매출 탭 컬럼 전환 + 수익성 요약 수식 전환 |

## 7. 숫자 표시 규칙

| 대상 | 형식 | 예시 |
|------|------|------|
| 면적 | 소수점 1자리 | 1,248.6m² |
| 비율 (건폐율, 용적률, 전용률) | 소수점 1자리 + % | 199.5% |
| 금액 (테이블 내) | 천원 단위, 천단위 구분 | 3,250,000 |
| 금액 (카드/배너) | 자동 단위 | 3억원, 92만원 |
| 수익률 | 소수점 1자리 + % | 7.1% |
| 층수 | 정수, 지하는 B 접두사 | 10층, B1 |
| 세대/주차 | 정수 | 28세대, 36대 |
| 입력 필드 | 천단위 구분, 소수점 없음 | 1,600,000 |

**자동 단위 환산 규칙:**
- 1만 미만: 원 단위
- 1만 이상 ~ 1억 미만: 만원 단위
- 1억 이상 ~ 1조 미만: 억원 단위
- 1조 이상: 조 단위

## 8. 프로젝트 상태 흐름

```
[생성] → WAITING → RUNNING → FINISHED
                            → FAILED
```

| 상태 | 설명 | 클라이언트 동작 |
|------|------|---------------|
| WAITING | AI 분석 대기 중 | 로딩 표시, 10초 폴링 |
| RUNNING | AI 분석 진행 중 | 로딩 표시, 10초 폴링 |
| FINISHED | 분석 완료 | 폴링 중단, 결과 표시 |
| FAILED | 분석 실패 | 폴링 중단, 에러 + 재시도 버튼 |
