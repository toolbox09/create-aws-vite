# 감리 입찰 및 계약 기능 명세서

> 기존 설계 입찰/계약 시스템 확장 · 작성일: 2026-03-10 · 상태: Draft

---

## 1. 도메인 개요

건축주가 **감리 입찰공고**를 등록하면 **감리업체(건축사/감리전문회사)**가 제안서를 제출하고, 선정 후 **감리용역계약 → 전자서명**으로 이어지는 구조.

```
감리 입찰공고 등록 → 감리 제안서 접수 → 업체 선정 → 감리용역계약 초안 → 전자서명 → 계약 체결
```

> **법적 배경:** 건축법 제25조에 따라 일정 규모 이상의 건축물은 **공사감리자 지정이 의무**. 3층 이상 또는 연면적 200m² 이상은 허가권자가 감리자를 지정하거나 건축주가 직접 선임.

> **설계·시공과의 관계:** 감리는 설계·시공과 **독립적**이어야 함 (이해 충돌 방지). 설계한 건축사가 감리를 겸할 수 있으나, 시공사와 감리자는 반드시 분리.

## 2. 설계·시공 대비 차이점 요약

| 구분 | 설계 | 시공 | 감리 |
|------|------|------|------|
| 참여 주체 | 건축사 | 시공사 | 감리업체 (건축사/감리전문) |
| 분야 구분 | 가설계/본설계 | 신축/증축/리모델링/인테리어 | **상주감리/비상주감리/책임감리** |
| 4단계 (요구사항) | 디자인요소+외장재 | 공법+자재+설비 | **감리 범위+검측항목+보고주기** |
| 비용 필드 | 설계비 | 공사비 | **감리비** |
| 제안서 핵심 | 설계 소견 | 견적서+시공 소견 | **감리계획서+감리비** |
| 계약서 양식 | 건축설계 표준계약서 | 건설공사 표준도급계약서 | **건설공사 감리용역계약서** |
| 계약서 핵심 | 기성일정+설계도서 | 기성일정+자재내역+하자보증 | **감리일정+검측계획+보고체계** |

## 3. 데이터 모델

### 3.1 공유 테이블 (변경 없음)

설계·시공과 동일하게 아래 테이블 공유:

- `bids`, `bid_categories` (`감리` 행), `bid_restrictions`, `bid_invitations`
- `bid_site`, `bid_building`, `bid_certifications`, `bid_likes`
- `proposals`, `proposal_attachments`
- `contracts`, `contract_items`, `contract_item_histories`, `contract_attachments`

### 3.2 bids 테이블 확장

| 컬럼 | 타입 | 설명 |
|------|------|------|
| supervision_type | enum | `상주감리` · `비상주감리` · `책임감리` — 감리 공고에서만 사용 (다른 분야는 NULL) |

> 감리 유형별 설명:
> - **상주감리**: 감리원이 현장에 상주. 대형 건축물, 다중이용건축물 등 의무 대상.
> - **비상주감리**: 정기 방문 (주 2~3회). 소규모 건축물.
> - **책임감리**: 감리전문회사가 설계·시공 전체에 대해 책임. 공공공사 등.

## 4. 화면 명세

### 4.1 입찰공고 등록 — 감리 분야 (`/bids/new`)

5단계 위저드 공유. **2단계, 3단계, 4단계가 감리 전용**으로 변형.

| 단계 | 이름 | 설계/시공과 차이 |
|------|------|-----------------|
| 1 | 사업 부지 설정 | **동일** |
| 2 | 입찰 정책 | 분야에서 `감리` 선택. 감리유형(상주/비상주/책임) 라디오 추가 |
| 3 | 건축 목적·규모 | 설계비/공사비 → **감리비**(min/max). **예상 공사기간**(개월) 추가 |
| 4 | **감리 요구사항** | 아래 상세 |
| 5 | 공고 신뢰 인증 | 건축가능 → **설계도서확보 + 시공계약확보** 인증 |

| 섹션 | 설계 | 감리 |

| 인증 항목 | 건축가능 | **설계도서확보 + 시공계약확보** |

## 5. 계약서 — 건설공사 감리용역계약서

### 5.1 계약서 양식

**`건설공사 감리용역계약서 (건축법 제25조 근거)`** 사용.

| # | 섹션 | 편집 | 설계/시공과 비교 |
|---|------|:---:|---------------|

| 9 | 첨부파일 | ✓ | 감리계획서, 감리원 자격증, 보험가입증명서 등 |

### 5.4 SupervisionTeamMember (감리원 배치계획, JSON 배열)

```typescript
interface SupervisionTeamMember {
  role: string;           // 직급/역할 (예: "총괄감리원", "분야별감리원", "보조감리원")
```

### 6.2 계약 상세 (`/contracts/:id`)

설계 계약 상세와 동일한 2단 레이아웃에서:
- **감리 개요 섹션** 추가 (감리유형, 범위, 기간)
- **감리원 배치계획 섹션** 추가
- **검측 및 보고계획 섹션** 추가
- 우측 카드에 **감리유형 배지, 감리기간, 감리원 수** 표시
- 타임라인 동일 (8단계)

### 6.3 계약 수정, 전자서명

설계/시공과 동일한 플로우. 양식만 감리 계약서로 교체.

## 9. 시공→감리 연계 시나리오

```
1. 건축주가 시공 계약을 체결한 후, 감리 입찰을 등록
2. 감리 입찰 등록 시 "시공 계약 연결" 옵션:
   - 시공 계약 ID를 선택하면 → 공사정보(기간, 시공사, 구조) 자동 연동
   - bid_supervision_requirements.linked_construction_contract_id에 저장
   - 감리 입찰 상세에 "시공사: OOO건설" 표시
3. 감리업체가 시공 정보를 확인하고 감리 제안서를 제출
4. 감리 계약서에 시공사 정보가 자동 반영
```

## 10. 설계 → 시공 → 감리 전체 플로우

```
┌────────────┐      ┌────────────┐      ┌────────────┐
│   설계 입찰   │      │   시공 입찰   │      │   감리 입찰   │
│   ↓ 선정     │      │   ↓ 선정     │      │   ↓ 선정     │
│   설계 계약   │─────→│   시공 계약   │─────→│   감리 계약   │
│   (건축사)    │ 설계도서│   (시공사)    │ 공사정보│   (감리업체)  │
│   ↓ 체결     │ 연계   │   ↓ 체결     │ 연계   │   ↓ 체결     │
│   설계 완료   │      │   착공       │      │   감리 착수   │
└────────────┘      │   ↓         │      │   ↓         │
                    │   준공       │      │   감리 완료   │
                    └────────────┘      └────────────┘
```

> 각 단계는 독립적으로도 진행 가능하며, 연계는 **선택사항**임.
> 연계 시 이전 계약의 정보(설계도서, 공사정보)가 자동 반영되어 편의성 향상.
