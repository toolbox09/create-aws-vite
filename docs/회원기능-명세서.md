# 회원 기능 명세서

> 현재 웹 목업(mock) 분석 기반으로 추정한 회원 기능 명세서.
> 모든 인증/회원 기능은 현재 `useAuthStore` (Zustand)로 목업 처리되어 있으며, 실제 백엔드 구현이 필요함.

---

## 1. 회원 유형 (User Roles)

| 코드 | 한글 | 설명 |
|------|------|------|
| `CL-P` | 건축주 (개인) | 개인 건축주. 입찰 등록, 파트너 검색/저장 가능 |
| `CL-C` | 건축주 (법인) | 법인 건축주. 개인 건축주와 동일 기능 + 사업자 정보 관리 |
| `PT` | 파트너 (전문가) | 설계사/시공사/감리사. 입찰 참여, 포트폴리오 관리, 프로필 공개 |
| `ADMIN` | 관리자 | 회원 관리, 라이센스 심사, 콘텐츠 관리 (목업의 `/admin` 라우트) |

---

## 2. 인증 (Authentication)

### 2.1 회원가입 (`/auth/signup`)

**진입 화면:** 가입 방법 선택

| 방법 | 대상 | 설명 |
|------|------|------|
| 소셜 간편 가입 (네이버/카카오) | **건축주 개인** 전용 | 본인인증 불필요, 소셜에서 이름/이메일 획득 |
| 본인인증으로 가입 | 모든 역할 | 휴대폰 본인인증 → 역할 선택 → 약관 → 계정 정보 |

> 로그인 페이지에서 소셜 버튼 클릭 시 신규 회원이면 `/auth/signup?social=naver|kakao`로 리다이렉트되어 소셜 가입 플로우가 자동 시작됨.

---

#### Path A: 소셜 간편 가입 (건축주 개인 전용, 4단계)

| 단계 | 내용 | 필드 |
|------|------|------|
| 0. 진입 | 소셜 인증 (네이버/카카오) | `socialProvider`, `name`, `email` 자동 획득 |
| 1. 약관 동의 | 건축주 약관 표시 | `agreements` |
| 2. 관심 분야 | 건축 용도 + 지역 선택 | `buildingUsages[]`, `regions[]` |
| 3. 완료 | 가입 완료 안내 | — |

- 본인인증 **불필요** (소셜 인증이 대체)
- 역할 선택 **불필요** (자동으로 CL-P)
- 비밀번호 **없음** (소셜 로그인 전용)

#### Path B: 본인인증 가입

**건축주(개인/법인) — 6단계:**

| 단계 | 내용 | 필드 |
|------|------|------|
| 1. 역할 선택 | 건축주(개인/법인) / 파트너 | `role` |
| 2. 본인인증 | 휴대폰 본인인증 (PASS 등) | `name`(실명), `phone`, `ci`, `di` |
| 3. 약관 동의 | 역할별 다른 약관 표시 | `agreements` |
| 4. 계정 정보 | 이메일/비밀번호 (+법인명) | `email`, `password`, `company` |
| 5. 관심 분야 | 건축 용도 + 지역 선택 | `buildingUsages[]`, `regions[]` |
| 6. 완료 | 가입 완료 안내 | — |

**파트너 — 8단계:**

| 단계 | 내용 | 필드 |
|------|------|------|
| 1. 역할 선택 | 파트너 선택 | `role` |
| 2. 본인인증 | 휴대폰 본인인증 (PASS 등) | `name`(실명), `phone`, `ci`, `di` |
| 3. 약관 동의 | 파트너 약관 표시 | `agreements` |
| 4. **사업자 인증** | 사업자등록증 업로드 (필수) → OCR 파싱 → 사무소명·주소·대표자·사업자번호 자동입력 (수정 가능) | `bizFile`, `bizCompany`, `bizAddress`, `bizOwner`, `bizRegNo` |
| 5. **자격 인증** | 설계/시공/감리 중 1개 자격증 업로드 (**선택**, 건너뛰기 가능) | `licenseType`, `licenseFile` |
| 6. 계정 정보 | 이메일/비밀번호 (사무소명은 4단계에서 입력됨) | `email`, `password` |
| 7. 관심 분야 | 전문 분야 + 건축 용도 + 지역 | `certTypes[]`, `buildingUsages[]`, `regions[]` |
| 8. 완료 | 가입 완료 안내 | — |

> **사업자 인증 (4단계):** 사업자등록증 업로드는 필수. 업로드 시 OCR/파싱으로 사무소명, 주소, 대표자명, 사업자등록번호가 자동 입력되며, 잘못된 정보는 직접 수정 가능. 관리자 심사 후 승인.

> **자격 인증 (5단계):** 선택사항. 가입 시 1개 분야만 인증 가능. 가입 후 마이페이지에서 추가 자격증 등록 가능. 인증 완료 시 프로필에 "인증 파트너" 뱃지 표시.

---

**역할별 약관 차이:**

| 약관 | 건축주 개인 | 건축주 법인 | 파트너 |
|------|:-:|:-:|:-:|
| 서비스 이용약관 | 필수 | 필수 | 필수 |
| 개인정보 수집·이용 동의 | 필수 | 필수 | 필수 |
| 개인정보 제3자 제공 동의 | 필수 | 필수 | 필수 |
| 만 14세 이상 확인 | 필수 | 필수 | 필수 |
| 사업자 정보 제공 동의 | — | **필수** | **필수** |
| 자격 정보 공개 동의 | — | — | **필수** |
| 마케팅 정보 수신 동의 | 선택 | 선택 | 선택 |

**필드 상세:**

```
-- 본인인증으로 자동 획득 (Path B) --
name: string             — 실명 (본인인증에서 획득, 수정 불가)
phone: string            — 전화번호 (본인인증에서 획득)
ci: string               — 연계정보 (중복가입 방지용, 암호화 저장)
di: string               — 중복확인정보 (사이트별 고유, 암호화 저장)

-- 소셜에서 자동 획득 (Path A) --
name: string             — 소셜 프로필 이름
email: string            — 소셜 이메일
socialProvider: string   — naver | kakao

-- 사용자 입력 (Path B만) --
email: string            — 이메일 (필수, 로그인 ID로 사용)
password: string         — 비밀번호 (필수, 8자 이상, 대소문자+숫자+특수문자)
company: string          — 회사/사무소명 (파트너/법인 건축주만 필수)
role: "CL-P"|"CL-C"|"PT" — 회원 유형 (필수)

-- 공통 --
certTypes: string[]      — 자격 유형 (파트너만): ["설계", "시공", "감리"]
buildingUsages: string[] — 관심 건물 용도: ["단독주택", "다세대주택", "근린생활", "오피스텔", "상가", "공장"]
regions: string[]        — 관심 지역: ["서울", "경기", "부산", "인천", "대전", "광주", "대구", "제주"]
```

**파트너(PT) 추가 제출 서류:**
- 사업자등록증 (필수) — 관리자 심사 후 승인 (`/admin/license`)
- 건축사 자격증 / 시공 면허 등 (선택) — 프로필에 "인증 뱃지" 부여

> 파트너는 가입 즉시 기본 기능 사용 가능하나, 자격 심사 완료 전까지 "인증 대기" 상태로 표시됨.

**비즈니스 로직:**
- Path B: CI 기반 중복가입 검증 (동일인 재가입 방지)
- Path A: 소셜 provider_id 기반 중복가입 검증
- 이메일 중복 검증 필요
- 비밀번호 강도 검증 (프론트 + 백엔드, Path B만)
- 본인인증 완료 시 이메일 인증은 생략 가능 (본인인증이 더 강력한 신원 확인)

### 2.2 소셜 로그인 (OAuth)

| 제공자 | 상태 | 비고 |
|--------|------|------|
| 네이버 | UI 존재 | 초록색 버튼 (`#03C75A`) |
| 카카오 | UI 존재 | 노란색 버튼 (`#FEE500`) |

**소셜 로그인 플로우:**
1. 소셜 인증 → 이메일/이름 정보 획득
2. 기존 회원이면 → 로그인 완료
3. 신규 회원이면 → `/auth/signup?social=naver|kakao`로 리다이렉트
   - Path A (소셜 간편 가입) 플로우 자동 시작: 약관 동의 → 관심 분야 → 완료
   - 자동으로 건축주 개인(CL-P) 역할 부여, 비밀번호 없음

### 2.3 로그인 (`/auth/login`)

```
email: string     — 이메일
password: string  — 비밀번호
```

**비즈니스 로직:**
- 로그인 성공 시 → Access Token + Refresh Token 발급 → `/map`으로 리다이렉트
- 로그인 실패 시 → 에러 메시지 표시
- **로그인 실패 제한:** 5회 연속 실패 시 30분 잠금 (브루트포스 방지)
- 로그인 유지 옵션 (remember me) — Refresh Token 만료 기간 연장 (7일 → 30일)

### 2.4 본인인증 (Identity Verification)

> PASS, NICE, KMC 등 본인인증 서비스 연동. 회원가입 외에도 비밀번호 찾기, 탈퇴 등에서 재사용.

**본인인증이 필요한 시점:**

| 시점 | 이유 |
|------|------|
| 회원가입 3단계 | 실명 확인 + 중복가입 방지 (CI) |
| 비밀번호 찾기 | 본인 확인 후 재설정 링크 발송 |
| 회원 탈퇴 | 본인 확인 후 탈퇴 처리 |
| 이름 변경 | 실명 변경 시 재인증 필요 |

**본인인증 응답 데이터:**
```
name: string     — 실명
phone: string    — 인증된 전화번호
birthDate: string — 생년월일
gender: string   — 성별
ci: string       — 연계정보 (64byte, 전 사이트 동일 → 중복가입 판별)
di: string       — 중복확인정보 (사이트별 고유)
```

### 2.5 비밀번호 찾기 (`/auth/password-find`)

**방법 1: 이메일로 찾기**
```
email: string — 가입된 이메일
```

**방법 2: 본인인증으로 찾기**
- 본인인증 완료 → CI로 가입된 계정 조회 → 이메일 일부 마스킹 표시 → 재설정 링크 발송

**비즈니스 로직:**
- 이메일 존재 여부와 관계없이 항상 성공 메시지 표시 (보안)
- 60초 재전송 쿨다운
- 이메일로 비밀번호 재설정 링크 발송 (토큰 포함)

### 2.5 비밀번호 재설정 (`/auth/password-reset?token=...`)

```
token: string           — URL 파라미터로 전달되는 재설정 토큰
newPassword: string     — 새 비밀번호
confirmPassword: string — 비밀번호 확인
```

**비밀번호 강도 기준 (5단계):**

| 레벨 | 라벨 | 조건 |
|------|------|------|
| 1 | 매우 약함 | 8자 미만 |
| 2 | 약함 | 8자 이상 |
| 3 | 보통 | 8자 이상 + 대소문자 혼합 |
| 4 | 강함 | 8자 이상 + 대소문자 + 숫자 |
| 5 | 매우 강함 | 8자 이상 + 대소문자 + 숫자 + 특수문자 |

**비즈니스 로직:**
- 토큰 유효성 검증 (만료/무효 시 에러 화면)
- 토큰 만료 시간: 1시간 (보안상 짧게 유지)
- 비밀번호 변경 성공 후 → 로그인 페이지로 안내

## 3. 마이페이지 (`/mypage?tab=...`)

### 3.1 대시보드 (`?tab=dashboard`)

| 항목 | 설명 |
|------|------|
| 통계 카드 4개 | 진행중 프로젝트, 받은 제안, 저장한 파트너, 새 메시지 |
| 빠른 액션 | 새 프로젝트 등록, 파트너 찾기 등 |
| 활성 입찰 목록 | 현재 진행중인 입찰 요약 |
| 최근 활동 | 타임라인 형태 |

### 3.2 프로젝트 관리 (`?tab=projects`)

- 상태 필터: 진행중 / 완료
- 프로젝트별 진행률 표시 (프로그레스 바)
- 프로젝트 상세 조회

### 3.3 입찰 관리 (`?tab=bids`)

- 필터: 전체 / 진행중 / 종료
- 내가 등록한 입찰 목록

### 3.4 저장한 입찰 (`?tab=saved-bids`)

- 북마크(하트) 토글
- "종료된 입찰 숨기기" 옵션

### 3.5 저장한 파트너 (`?tab=saved-partners`)

- 그리드 레이아웃
- 파트너별 포트폴리오 수 표시

### 3.6 개인정보 수정 (`?tab=personal`)

```
name: string        — 실명 (본인인증으로만 변경 가능)
email: string       — 이메일 (변경 시 새 이메일 인증 필요)
phone: string       — 전화번호 (본인인증으로 변경)
memberType: string  — 회원 유형 (표시만, 변경 불가)
socialLogin: string — 연동된 소셜 계정 (연결/해제 가능)
joinDate: date      — 가입일 (표시만)
```

### 3.7 보안 설정 (`?tab=security`)

| 기능 | 설명 |
|------|------|
| 비밀번호 변경 | 현재 비밀번호 + 새 비밀번호 + 확인 |
| 2단계 인증 (2FA) | 활성/비활성 상태 표시 |
| 로그인 기기 관리 | 접속 기기 목록 + 로그아웃 |

### 3.8 알림 설정 (`?tab=notifications`)

| 카테고리 | 이메일 | 푸시 |
|----------|--------|------|
| 입찰 알림 | ✅ | ✅ |
| 제안 알림 | ✅ | ✅ |
| 계약 알림 | ✅ | ✅ |
| 채팅 알림 | ✅ | ✅ |
| 마케팅 알림 | ✅ | ✅ |

### 3.9 결제 수단 (`?tab=payment`)

- 결제 수단 등록/관리 (현재 빈 상태)

### 3.10 환경 설정 (`?tab=preferences`)

```
language: string   — 언어 (한국어 기본)
region: string     — 지역
currency: string   — 통화 (KRW)
areaUnit: string   — 면적 단위 (㎡/평)
theme: string      — 테마 (라이트/다크)
```

### 3.11 회원 탈퇴 (`?tab=withdraw`)

- 탈퇴 경고 안내 표시
- 탈퇴 사유 선택 (라디오 버튼)
- **본인인증 재확인** 후 탈퇴 처리
- 탈퇴 후 CI 보관 기간: 30일 (재가입 방지 / 부정 이용 방지)
- 개인정보 파기: 탈퇴 즉시 (법적 보관 의무 항목 제외)

## 4. 관리자 기능 (`/admin`)

### 4.1 회원 관리 (`/admin/members`)

**회원 목록 테이블:**

| 필드 | 설명 |
|------|------|
| `id` | 회원 ID |
| `name` / `company` | 이름 또는 회사명 |
| `email` | 이메일 |
| `phone` | 전화번호 |
| `type` | 건축주 / 파트너스 |
| `status` | 활성 / 정지 |
| `joinDate` | 가입일 |

**필터:**
- 회원 유형: 전체 / 건축주 / 파트너스
- 상태: 전체 / 활성 / 정지
- 검색: 이름, 이메일, 회사명

**관리 기능:**

## 6. 필요한 API 엔드포인트 (추정)

### 인증
```
POST   /api/auth/signup              — 회원가입
POST   /api/auth/login               — 로그인 (Access + Refresh Token 발급)
POST   /api/auth/logout              — 로그아웃 (Refresh Token 무효화)
POST   /api/auth/refresh             — Access Token 갱신
POST   /api/auth/password-find       — 비밀번호 찾기 (이메일 발송)
POST   /api/auth/password-reset      — 비밀번호 재설정
GET    /api/auth/me                  — 현재 사용자 정보
```

### 본인인증
```
POST   /api/auth/identity/request    — 본인인증 요청 (인증 팝업 URL 반환)
POST   /api/auth/identity/verify     — 본인인증 결과 검증 (CI/DI 획득)
```

### 소셜 로그인
```
GET    /api/auth/oauth/naver         — 네이버 OAuth 시작
GET    /api/auth/oauth/naver/callback — 네이버 OAuth 콜백
GET    /api/auth/oauth/kakao         — 카카오 OAuth 시작
GET    /api/auth/oauth/kakao/callback — 카카오 OAuth 콜백
```

### 마이페이지
```
GET    /api/users/me                 — 내 프로필 조회
PATCH  /api/users/me                 — 내 프로필 수정
PATCH  /api/users/me/password        — 비밀번호 변경
DELETE /api/users/me                 — 회원 탈퇴
GET    /api/users/me/notifications   — 알림 설정 조회
PATCH  /api/users/me/notifications   — 알림 설정 변경
GET    /api/users/me/preferences     — 환경 설정 조회
PATCH  /api/users/me/preferences     — 환경 설정 변경
GET    /api/users/me/devices         — 로그인 기기 목록
DELETE /api/users/me/devices/:id     — 기기 로그아웃
```

### 관리자
```
GET    /api/admin/members            — 회원 목록 (필터, 검색, 페이지네이션)
GET    /api/admin/members/:id        — 회원 상세
PATCH  /api/admin/members/:id/status — 회원 상태 변경 (활성/정지)
```

## 7. 데이터베이스 테이블 (추정)

### `users` 테이블
```sql
id              UUID PRIMARY KEY DEFAULT gen_random_uuid()
email           VARCHAR(255) UNIQUE NOT NULL
password_hash   VARCHAR(255)          -- NULL if social-only
name            VARCHAR(100) NOT NULL  -- 본인인증 실명
phone           VARCHAR(20) NOT NULL   -- 본인인증 전화번호
company         VARCHAR(200)           -- 파트너/법인 건축주
role            VARCHAR(10) NOT NULL   -- CL-P, CL-C, PT
status          VARCHAR(10) NOT NULL DEFAULT 'active'  -- active, suspended, withdrawn
avatar_url      VARCHAR(500)
ci              VARCHAR(255) UNIQUE    -- 본인인증 연계정보 (암호화, 중복가입 방지)
di              VARCHAR(255)           -- 본인인증 중복확인정보 (암호화)
identity_verified BOOLEAN DEFAULT FALSE -- 본인인증 완료 여부
login_fail_count INT DEFAULT 0         -- 연속 로그인 실패 횟수
locked_until    TIMESTAMPTZ            -- 계정 잠금 해제 시각 (NULL이면 잠금 아님)
agreed_marketing BOOLEAN DEFAULT FALSE -- 마케팅 수신 동의
created_at      TIMESTAMPTZ DEFAULT NOW()
updated_at      TIMESTAMPTZ DEFAULT NOW()
```

### `user_oauth` 테이블
```sql
id              UUID PRIMARY KEY DEFAULT gen_random_uuid()

created_at      TIMESTAMPTZ DEFAULT NOW()

```

## 8. 구현 우선순위 (제안)

| 순위 | 기능 | 이유 |
|------|------|------|
| P0 | 회원가입 + 로그인 + JWT (Access/Refresh) | 모든 기능의 기반 |
| P0 | 본인인증 연동 (PASS/NICE) | 회원가입 필수 단계 |
| P0 | `users` + `user_interests` + `refresh_tokens` 테이블 | 데이터 저장 필수 |
| P1 | 약관 동의 플로우 | 법적 필수 요건 |
| P1 | 비밀번호 찾기/재설정 + 로그인 실패 잠금 | 기본 인증 플로우 + 보안 |
| P1 | 개인정보 수정 + 비밀번호 변경 | 기본 마이페이지 |
| P2 | 소셜 로그인 (네이버/카카오) | 한국 서비스 필수 |
| P2 | 관리자 회원 관리 + 파트너 자격 심사 | 운영 필수 |
| P3 | 알림 설정, 환경 설정 | 부가 기능 |
| P3 | 2FA, 기기 관리 | 보안 강화 |
| P4 | 회원 탈퇴, 결제 수단 | 후순위 |
